# AI Resume Matcher

AI Resume Matcher is a Streamlit-based web application that compares resumes with job descriptions using keyword analysis.

## Features

- Upload Resume PDF
- Paste Job Description
- Keyword Matching
- Missing Skills Detection
- Match Score Generation
- Interview Question Suggestions

## Technologies Used

- Python
- Streamlit
- pdfplumber

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
